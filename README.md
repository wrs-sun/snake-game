# 🐍 贪吃蛇游戏

使用原生 HTML / CSS / JavaScript 实现的经典贪吃蛇游戏，支持桌面端和移动端。

## 🎮 在线游玩

- GitHub Pages: [https://wrs-sun.github.io/snake-game/](https://wrs-sun.github.io/snake-game/)
- 或直接在浏览器打开 `index.html`

## 🕹️ 操作说明

| 操作 | 按键 |
|------|------|
| 上移 | `↑` 或 `W` |
| 下移 | `↓` 或 `S` |
| 左移 | `←` 或 `A` |
| 右移 | `→` 或 `D` |
| 重新开始 | `空格` 或 点击按钮 |
| 触摸屏 | 滑动屏幕控制方向 |

## ✨ 特性

- 🎨 深色渐变主题 + 网格背景
- 👀 带眼珠的蛇头，眼珠跟随移动方向转动
- 🎨 蛇身颜色渐变（从蛇头到蛇尾）
- 💥 吃到食物时迸发金色粒子特效
- 🍎 红色食物带高光反射
- 👑 最高分本地持久化存储（localStorage）
- ⚡ 实时速度调节滑块（40ms ~ 200ms），五档调速
- 📱 移动端触摸滑动支持
- 🏆 吃满整个棋盘即胜利

## 🎛️ 速度调节

滑块支持五档速度，游戏中拖拽滑块**实时生效**，无需重新开始：

| 速度档位 | 间隔时间 |
|----------|----------|
| 极快 | ≤ 60ms |
| 快 | 65ms ~ 85ms |
| 中 | 90ms ~ 120ms |
| 慢 | 125ms ~ 160ms |
| 极慢 | ≥ 165ms |

速度偏好会保存在浏览器中，下次打开游戏自动恢复。

## 🏗️ 技术栈

- HTML5 Canvas 渲染
- 纯 CSS3 样式（渐变、阴影、动画）
- 原生 JavaScript（无依赖）
